- مبالغ پایه در ریال؛ اگر داشبورد میلیون ریال نشان دهد، برچسب مقیاس الزامی است.

## گام توسعه پس از تأیید کاربر
آماده‌سازی سامانه چندسکویی و چندکاربره Android + Windows desktop + Web با داده‌های مشترک و همگام‌سازی کنترل‌شده:
1. جداسازی موتور محاسبات مالی، ذخیره و API از رابط کاربری و اتصالات اختصاصی اندروید.
2. شناسه پایدار سراسری اسناد، نسخه/زمان تغییر، actor، شناسه دستگاه و عملیات امن و تکرارناپذیر برای تسویه.
3. احراز هویت مرکزی؛ کاربران، نقش‌ها، مجوزهای عملیات (RBAC) و محدوده داده هر واحد سازمانی؛ اعمال در سرور، نه صرفاً مخفی‌سازی رابط.
4. پایگاه داده مرکزی و API با کنترل هم‌زمانی، ردپای حسابرسی غیرقابل‌دستکاری، پشتیبان‌گیری و بازیابی.
5. مدل online-first با قابلیت آفلاین کنترل‌شده، صف تغییرات و حل تداخل؛ اعمال کنترل دقیق‌تر برای اسناد قطعی و تسویه.
6. نسخه دسکتاپ با استفاده مجدد از هسته موجود و رابط متناسب صفحه بزرگ.
7. همکاری واحدها در ورود و تصویب بودجه در چارچوب یک بودجه جامع شرکت.
- این موارد در نسخه ۰.۷.۶ پیاده‌سازی نشده‌اند و صرفاً نقشه راه توافق‌شده هستند.
